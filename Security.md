# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates:

| Version | Supported |
|----------|-----------|
| Latest Release | ✅ |
| Previous Release | ✅ |
| Older Releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### How to Report

Please provide the following information:

- Description of the vulnerability
- Steps to reproduce the issue
- Impact assessment
- Affected version(s)
- Proof-of-concept (if available)
- Any suggested remediation

### Contact

Submit security reports through one of the following methods:

- Create a private security advisory in GitHub (preferred)
- Contact the repository maintainers directly
- Use your organization's established security reporting process

### Response Process

Upon receiving a report, maintainers will:

1. Acknowledge receipt of the report.
2. Validate and assess the vulnerability.
3. Develop and test a fix if necessary.
4. Coordinate responsible disclosure.
5. Release security updates and advisories as appropriate.

### Responsible Disclosure

Please do not publicly disclose security vulnerabilities until they have been reviewed and addressed by the maintainers. Responsible disclosure helps protect users and allows sufficient time for remediation.

## Security Best Practices

When contributing to this project:

- Never commit secrets, passwords, API keys, or certificates.
- Store sensitive values in environment variables or secure secret stores.
- Use `.gitignore` to exclude configuration files containing secrets.
- Keep dependencies up to date.
- Review pull requests for security implications.
- Follow the principle of least privilege.
- Enable security scanning and dependency alerts when available.

## Supported Security Features

This repository may use the following GitHub security features:

- Dependency Graph
- Dependabot Alerts
- Dependabot Security Updates
- Code Scanning
- Secret Scanning
- Security Advisories

## Scope

This policy applies only to this repository and its associated source code, documentation, workflows, and configuration files contained within the repository.

Thank you for helping keep this project and its users secure.
